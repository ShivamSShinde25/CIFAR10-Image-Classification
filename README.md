# CIFAR-10 Image Classification

## About
This project classifies images into 
10 categories using Deep Learning.
Dataset contains 60,000 images.

## Classes
airplane, automobile, bird, cat, deer,
dog, frog, horse, ship, truck

## What I Did
- Loaded CIFAR-10 dataset
- Visualized sample images
- Normalized pixel values
- Built and trained ANN model
- Built and trained CNN model
- Compared ANN vs CNN accuracy
- Plotted confusion matrix

## Results
| Model | Accuracy |
|-------|----------|
| ANN   | 48%      |
| CNN   | 69%      |

## Libraries Used
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## How To Run
1. Open .ipynb in Google Colab
2. Run all cells in order
